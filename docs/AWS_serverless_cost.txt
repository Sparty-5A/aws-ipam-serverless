Potential Cost Risks & How to Avoid Them
Risk 1: Accidental High Usage 💸
What Could Happen:

Someone discovers your API endpoint
Automated script hits your API 1M times/day
Massive bill

Prevention:
# Add to infrastructure/api.py

# Option 1: API Gateway Throttling (FREE!)
stage = aws.apigatewayv2.Stage(
    f"{project_name}-api-stage",
    api_id=api.id,
    name="prod",
    auto_deploy=True,
    
    # ADD THIS:
    default_route_settings=aws.apigatewayv2.StageDefaultRouteSettingsArgs(
        throttling_burst_limit=100,    # Max 100 requests at once
        throttling_rate_limit=10,      # Max 10 requests/second
    ),
)

Cost Protection:

✅ Limits requests to 10/second
✅ Prevents runaway costs
✅ Still allows normal testing


Risk 2: Forgetting to Delete (destroy)
What Could Happen:

Deploy and forget
Small charges accumulate ($0.01/month)
Over 5 years = $0.60 total

Prevention:
# Set a reminder to check quarterly
# OR just destroy when done testing

pulumi destroy
```

**Cost of forgetting:**
- After 12 months: $0.01/month = $0.12/year
- Over 5 years: $0.60 total

**Not a big risk!**

### **Risk 3: DynamoDB Massive Data Growth** 💸

**What Could Happen:**
- Store 100,000 subnets
- Store 10 million IP allocations
- Exceed 25 GB free tier

**Calculation:**
```
Current: 2.2 MB for 1,000 IPs

To exceed 25 GB free tier:
25 GB / 2.2 MB per 1,000 = 11.4 million IPs

You'd need to allocate 11 MILLION IPs to pay anything!

Reality Check:

Entire IPv4 internet = 4 billion IPs
Typical enterprise = 100,000 IPs max
Your testing = 100 IPs

Cost Risk: Near zero ✅

Risk 4: Lambda Timeout Loops 💸
What Could Happen:

Bug causes Lambda to run for 15 minutes (max)
1,000 stuck Lambda executions
High compute cost

Current Protection:
# In infrastructure/compute.py
lambda_function = aws.lambda_.Function(
    timeout=30,  # ← Kills function after 30 seconds
    memory_size=256,
)
```

**Worst Case Scenario:**
```
1,000 stuck functions × 30 seconds × 0.256 GB = 7,680 GB-seconds

FREE TIER COVERS: 400,000 GB-seconds
WORST CASE USAGE:  7,680 GB-seconds
PERCENTAGE USED:   1.9% of free tier

COST: Still $0!

Cost Risk: Zero ✅

🛡️ Cost Protection Recommendations
1. Set Up AWS Billing Alerts (Do This First!)
# In AWS Console:
# 1. Go to Billing → Billing preferences
# 2. Enable "Receive Free Tier Usage Alerts"
# 3. Set alert threshold: $1.00

# Or via AWS CLI:
aws budgets create-budget \
  --account-id YOUR_ACCOUNT_ID \
  --budget file://budget.json
  
budget.json:
{
  "BudgetName": "IPAM-System-Budget",
  "BudgetLimit": {
    "Amount": "1.00",
    "Unit": "USD"
  },
  "TimeUnit": "MONTHLY",
  "BudgetType": "COST"
}

This alerts you if cost exceeds $1/month ✅

2. Add CloudWatch Alarm
# Add to infrastructure/storage.py

import pulumi_aws as aws

# Create SNS topic for alerts
alert_topic = aws.sns.Topic(
    f"{project_name}-cost-alert",
    name=f"{project_name}-cost-alert",
)

# Subscribe your email
aws.sns.TopicSubscription(
    f"{project_name}-email-alert",
    topic=alert_topic.arn,
    protocol="email",
    endpoint="your-email@example.com",  # ← YOUR EMAIL
)

# Create alarm for API Gateway requests
aws.cloudwatch.MetricAlarm(
    f"{project_name}-high-api-usage",
    comparison_operator="GreaterThanThreshold",
    evaluation_periods=1,
    metric_name="Count",
    namespace="AWS/ApiGateway",
    period=3600,  # 1 hour
    statistic="Sum",
    threshold=10000,  # Alert if > 10k requests/hour
    alarm_description="High API usage detected",
    alarm_actions=[alert_topic.arn],
)

This emails you if usage spikes ✅

3. Enable Cost Explorer
# In AWS Console:
# 1. Go to Cost Explorer
# 2. Enable Cost Explorer (free)
# 3. View daily costs

# Check costs:
aws ce get-cost-and-usage \
  --time-period Start=2025-12-01,End=2025-12-03 \
  --granularity DAILY \
  --metrics BlendedCost
